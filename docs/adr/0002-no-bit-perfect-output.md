# v1 不做位精确输出

产品的「通用」指格式通用，不指发烧。v1 的输出链路只承诺三件事：正确解码、
正确下混、只在必要时重采样；始终走系统默认设备与系统混音器，不提供
WASAPI 独占、CoreAudio hog mode、ALSA hw 直连，也不做 DSD 原生或 DoP。

## 考虑过的选项

**做位精确**：三平台是三套完全不同的设备管理，还要处理采样率协商、独占期间的
热插拔、以及「绕过重采样」与现有设备跟随策略的冲突，工作量与「格式通用」主线
不在一个量级。

## 后果

- 「位精确」「直通」不写进 README 的能力表，也不作为 issue 的验收条件。
- 将来若要加独占输出，不能只加一个开关：必须同时解决设备协商、热插拔恢复、
  重采样旁路，届时应作为新的 ADR 重新立项，而不是在现有 `output::open` 里加分支。
- 现有「跟随设备默认格式」的行为是有意为之，不要以「没做独占」为由去改写它。
