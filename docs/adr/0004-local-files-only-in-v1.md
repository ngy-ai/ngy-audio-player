# v1 只播本地文件，不接网络流

内置 ffmpeg 之后 `ffmpeg -i <URL>` 几乎免费可用，但这不代表流是便宜的：整条链路
以 `Path` 为类型（`Command::Load`、`TrackMeta.path`、`library.txt`），Symphonia
那条路径还是 `File::open`。接流要先抽象出「媒体来源」，然后必须定义无限时长怎么
显示、seek 要不要禁用、断线重连算谁的错、缓冲进度给不给 UI。

v1 不接。范围写在 README 的已知边界里，并说明理由。

## 后果

- 「通用」的边界是**格式**，不是**来源**：本地文件里的任何编码都算通用，网络电台不算。
- 「粘贴 URL 就播」是唯一可接受的中间态，但它必须排在「媒体来源」抽象之后，
  不属于 v1。
- 队列、列表、持久化里出现的仍然是路径，不要为了让将来好改而提前引入泛型来源类型。
