# v1 范围

定位是**格式通用**：同一份程序能打开并播对任何编码、任何容器里的音频。这份清单是
达成该定位的交付边界，也是「作为一个通用播放器还缺什么」的答案。

缺口不在格式数量上——格式覆盖已经比多数同类做得好。缺的是**播对的五个正确性缺口、
三个基础设施缺口、五项发布能力**，以及一份把「不做什么」写清楚的清单。

括注里的 `path:line` 指向当前实现的位置，用来判断改哪里，不是承诺的落点。

## 一、阻塞发布

不修完就不能对外声称「通用」。其中 1、2、3、7 条**现在就是 bug**，不属于新特性。

1. **5.1 下混** —— `to_stereo` 对超过两声道的源只取前两路（`decode/mod.rs:81-87`）。
   AC-3 / DTS 的对白在中置、低频在 LFE，等于内容缺失。改为 ITU-R BS.775 下混
   （中置与环绕各 0.707 进左右，LFE 丢弃），带峰值保护；`testdata/` 补一个 5.1 样本
   与断言。
2. **采样格式全覆盖** —— `output.rs:68` 遇到 I24 / U32 / F64 直接报错，该设备上
   任何格式都不出声。补齐分支。
3. **设备热插拔** —— 现在只打日志（`output.rs:179-182`）。订阅设备变化，默认设备
   改变时重建流，不能靠重启应用。
4. **队列下移引擎 + 无缝切轨** —— 见 [ADR 0003](adr/0003-queue-owned-by-engine.md)。
   `Load` 会先清空缓冲（`engine.rs:185`），引擎不知道下一首就不可能无缝；而「下一首
   是谁」现在由 UI 算（`player_view.rs:361-364`）。
5. **CUE 分轨** —— 见 [ADR 0005](adr/0005-cue-tracks-are-real-tracks.md)。曲目标识
   从路径变成 `(路径, 起, 止)`，去重键、持久化、进度计算必须一起改。
6. **随机与循环进引擎** —— 现在 `RepeatMode` 在 UI 侧（`player_view.rs:40-72`），
   随机完全没有。随机必须是**预先算好的打乱序列**，否则「上一首」没有定义。
7. **列表虚拟化** —— 全量 `.child()` 摊开（`player_view.rs:1634-1681`）且 `tick`
   每 80ms 无条件 `notify`（`:366-367`），约 3000 首开始掉帧。行高已固定 52px，
   具备换成 `uniform_list` 的前提。目标：单个列表 2 万条内流畅滚动。
8. **持久化** —— 见 [ADR 0006](adr/0006-private-format-for-storage.md)。列表升级为
   带时间窗、版本号、原子写；新增 `config.toml` 存音量、窗口几何、主题、上次曲目与
   位置；支持 m3u8 导入导出（有损，需明示）。
9. **列表内搜索与排序** —— 过滤即输入，排序键为标题 / 艺人 / 专辑 / 时长 / 加入时间。
   不做曲库索引。

第 4、5、6 条是**同一次重构的四个侧面**（队列搬进引擎、无缝、随机、分轨），共享
「下一首是谁」的唯一权威来源。拆开做等于做四遍。

## 二、发布工程

10. **内置 LGPL 构建的 ffmpeg + 降级路径** —— 见
    [ADR 0001](adr/0001-bundle-lgpl-ffmpeg.md)。这是「通用」能否成为公开承诺的关键。
11. **三平台产物** —— Windows MSI 与免安装 zip、macOS dmg 并做 Developer ID 签名与
    公证、Linux AppImage 与 deb。Windows / Linux 暂不买代码签名证书，交付文档写清
    首次运行如何放行。
12. **媒体键与系统「正在播放」** —— `souvlaki` 一个 crate 覆盖 Windows SMTC /
    Linux MPRIS / macOS Now Playing。
13. **滚动日志 + 复制诊断信息** —— 日志落在配置目录并限大小轮转，界面里一键复制
    解码后端选择、ffmpeg 路径与 stderr 尾部、输出设备配置、错误原文。没有它，
    前面所有「播对」都无法被验证。
14. **面向用户的文案集中到一处** —— 不为 i18n，只为错误信息能统一审校；v1 只有中文。
15. **默认播放器登记（Windows）** —— 见 [ADR 0007](adr/0007-register-but-never-force-default.md)、
    [ADR 0008](adr/0008-force-default-is-an-explicit-opt-in.md)。默认只登记候选、不代写
    `UserChoice`，用户要点一次才算默认；此外提供显式的「直接设为默认」，由程序自己算哈希
    写 `UserChoice`（绕过系统保护，更新后可能失效，所以文案必须说清代价）。
    macOS / Linux 的等价物跟随各自产物格式一起做。

## 三、v1 明确不做

写进 README，避免反复被提。

- 位精确 / 独占输出 / DSD 原生 —— [ADR 0002](adr/0002-no-bit-perfect-output.md)
- 网络流、URL 输入、检查更新 —— 一切运行时网络请求，
  [ADR 0004](adr/0004-local-files-only-in-v1.md)
- 曲库视图：跨列表索引、文件夹扫描、按专辑 / 艺人浏览
- 歌词（LRC 与内嵌）、ReplayGain / EBU R128、EQ / 声道平衡、变速变调
- 标签写回与批量编辑
- MIDI、CD 抓轨、播客章节
